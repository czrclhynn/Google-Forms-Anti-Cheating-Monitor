Limitations

Supported (browser level): Google Forms detection; tab switching; active tab domain; ChatGPT/AI domain detection; configurable website blocking; new-tab handling; fullscreen; copy/paste; focus; browser shortcuts; DevTools shortcut attempts.
Not possible with a standard extension: detecting Word, Notepad, Acrobat or other desktop processes; blocking Alt+Tab or OS shortcuts; detecting phones or other devices; guaranteeing nobody can cheat; blocking DevTools opened from browser menus. The extension cannot read AI site conversations, only the domain.
Needs institution controls: managed ChromeOS, browser or Windows kiosk mode, device management, or a native desktop monitoring client (the DESKTOP_APPLICATION_OPENED event is reserved for one).
Privacy: monitoring runs only during a started, approved exam. No webcam, microphone, history, files, passwords, or form answers are read. Events are "potential violations" for teacher review, not proof.
